## ✨ الميزات الرئيسية / Key Features

### 🕷️ السكرابينج الذكي

- استخراج تلقائي للمنتجات من URLs
- دعم مواقع متعددة (Next.co.uk, Amazon, وغيرها)
- استخراج الصور والـ Variants والأسعار
- User-Agent rotation لتجنب الحظر

### 💰 إدارة الأسعار

- قواعد تسعير مخصصة
- Multipliers و Markups
- Rounding rules (.99, .00)
- تحويل العملات

### 🔄 المزامنة مع Shopify

- ربط المنتجات تلقائياً
- تحديث الأسعار والمخزون
- إدارة الـ Variants
- Sync jobs tracking

### 🗄️ قاعدة بيانات قوية

- Supabase PostgreSQL
- 14 جدول مترابط
- Real-time capabilities
- Auto-generated APIs
